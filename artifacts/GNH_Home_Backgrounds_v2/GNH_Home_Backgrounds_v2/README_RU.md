# GameNight Host — фоны главной, версия 2

Комплект под четыре существующие темы приложения. Это первый этап нового главного экрана — фон. Элементы интерфейса собираются поверх него отдельно.

| Тема | Оттенки по вашим скриншотам | Резервный цвет центра |
| --- | --- | --- |
| Neon | Почти чёрный синий, фиолетовый, фуксия, голубое свечение | `#060A1B` |
| Light | Светлый лавандовый, нежно-розовый и бледно-голубой | `#F6F4FF` |
| Sunset | Светлый кремово-персиковый, кораллово-розовые акценты | `#FFF5F0` |
| Calm | Светлый серо-белый, прохладный туман, приглушённый шалфейный | `#F5F7F6` |

Sunset и Calm в этой версии светлые. Предыдущие тёмно-бордовый и тёмно-зелёный варианты в комплект не входят.

## Как передать Cursor

1. Распакуйте весь архив в корень проекта, сохранив папку `GNH_Home_Backgrounds_v2`.
2. Откройте проект в Cursor.
3. Передайте агенту файл `CURSOR_PROMPT_RU.md` из этой папки либо скопируйте его содержимое в чат.
4. После выполнения проверьте четыре темы на главной. Промпт просит реализовать подключение и выполнить проверки.

## Что внутри

- `assets/` — WebP для приложения, по обычной и мобильной версии на тему. Подключать в production именно их.
- `originals/` — четыре исходных PNG для дальнейшей работы с графикой. Не импортировать их в production.
- `references/` — ваши четыре скриншота текущих тем и исходный референс будущего главного экрана.
- `integration/` — пример декоративного React-компонента и изолированного CSS. Cursor должен адаптировать его к реальному проекту.
- `palette.json` — ориентиры палитры и происхождение образцов.
- `asset-manifest.json` — размеры, вес и контрольные суммы файлов.
- `preview.html` — локальный просмотр фонов с переключением темы и размера. Можно открыть напрямую в браузере.
- `CURSOR_PROMPT_RU.md` — полное задание для Cursor на русском.
- `VALIDATION_RU.md` — выполненные проверки и что нужно проверить после интеграции.

Все четыре изображения имеют одинаковую композицию: кубики и свечение сверху и по краям, камни в нижних углах, свободный центр. Новые иллюстрации воссозданы по референсу и приведены к цветам текущих тем. Цвета из скриншотов — ориентиры; при подключении точные переменные существующего проекта имеют приоритет.

## Принцип адаптации

В примере одно изображение выбранной темы используется дважды: верхняя часть прикреплена к верху главной, нижняя — к её низу. CSS-маски плавно смешивают их с однотонной основой. Это сохраняет пропорции кубиков и не растягивает камни на длинной странице. Два одинаковых URL используют один и тот же загруженный ресурс.

Изображения декоративные: `alt=""`, `aria-hidden`, `pointer-events: none`. Главная отображается сразу на резервном цвете; загрузка фона не управляет показом контента.

Пример в существующей главной:

```tsx
<main className="gnh-home-stage">
  <HomeBackground theme={existingTheme} />
  {/* Текущая разметка главной, без изменения функций. */}
</main>
```

`existingTheme` здесь обозначает значение из действующего переключателя. Если реальные ключи отличаются от `neon | light | sunset | calm`, Cursor должен сделать явное соответствие у места использования. Новый провайдер темы и новое хранилище не нужны.

Не следует переносить в public весь архив: `originals`, `references`, инструкции и просмотрщик предназначены для разработки. В приложение попадают только нужные WebP и адаптированное подключение.
