# Задание для Cursor: новые обложки GameNight Host

Подключи изображения из этого пакета к СУЩЕСТВУЮЩИМ играм приложения. Это замена визуальных ассетов, без переработки приложения.

## Источник данных
- Открой ASSET_MAP.json и таблицу ASSET_MAP.md: там точное соответствие названия игры и файла.
- Используй assets/*.webp в интерфейсе. originals/*.png — исходники, их не нужно включать в клиентский бандл.
- Сопоставь реальные идентификаторы игр в текущем репозитории по названию/существующему каталогу. Поле key в карте — имя ассета, а не команда переименовать game ID. aliases — только помощь для поиска.
- Если конкретной игры в проекте нет, пропусти её и укажи это в отчёте. Не создавай выдуманные записи и не заменяй другую игру похожей.

## Подключение
1. Сначала найди действующий источник обложек каталога, главной и рулетки. Сохрани существующий способ хранения ассетов и маршрутизацию.
2. Скопируй WebP в подходящую публичную папку проекта; учитывай реальный Vite base / GitHub Pages / Capacitor path, не предполагай корневой домен.
3. Обнови ссылки на изображения только соответствующих 15 игр. Один файл — одна игра. Не используй общий спрайт, большой коллаж, фоновые координаты, CSS zoom или canvas для извлечения обложек.
4. Используй те же ассеты в карточках, избранном, результатах рулетки и деталях игры, где эти поверхности уже существуют. Не добавляй новую навигацию или новые экраны.

## Отображение без сильного приближения
- Все картинки горизонтальные 3:2. Для каталога выдели ОТДЕЛЬНУЮ область изображения aspect-ratio:3/2 с шириной 100%. Заголовок и метаданные размести под ней или в существующей читабельной области, не загораживая лица.
- Сам img: width:100%; height:100%; display:block; object-fit:contain; object-position:50% 50%. Допускается object-fit:cover только в контейнере того же 3:2, где обрезания фактически нет.
- Для существующих маленьких квадратных миниатюр/рулетки показывай всю сцену через contain на согласованной фиолетовой подложке. Не растягивай портреты на весь узкий сектор колеса; размести аккуратную отдельную миниатюру.
- Не увеличивай изображения при наведении: без scale(1.1), transform zoom, background-size:cover для произвольной формы, двойного кадрирования и искусственного апскейла.
- Изображения без встроенного текста. Названия — реальный HTML текст из game.title. Сохрани существующие названия, не выводи имена файлов или aliases.
- Сохрани крупные читаемые названия. Ориентир: каталог 28–32px desktop, 24–28px mobile при достаточной ширине. Если узкая карточка не вмещает название, используй перенос строк/уменьшение числа колонок, без обрезки заголовков и многоточия. Это ориентир, адаптируй к текущему интерфейсу.
- На колесе названия также отдельным текстом, крупнее мелких подписей. Не меняй количество игроков, вероятность выбора, перечень доступных игр, правила доступа или логику рулетки ради картинок.

## Что сохранить
Все текущие игры, колоды, вопросы, категории, описания, реальные диапазоны игроков, таймеры, счёт, роли, тарифы, Premium-права, оплату, согласия, документы, авторизацию, Telegram SDK, Capacitor, офлайн-режим, текущие маршруты, callbacks и хранение избранного.
Сохрани одобренные фон, портал, общий дизайн и уже сделанные исправления скорости загрузки. Не заменяй реальные данные демо-данными из визуальных прототипов.

## Анимации и скорость
- Не добавляй заставку, видео или задержку перед входом в игру. Игра открывается сразу через существующий обработчик.
- Не возвращай удалённую двухсекундную анимацию при открытии.
- Существующие лёгкие свечения/наклоны можно оставить, учитывая prefers-reduced-motion. Не добавляй большие видеозависимости.
- Ниже первого экрана используй loading="lazy" и decoding="async" для img; задай width/height или aspect-ratio для отсутствия скачков.
- Не загружай все 15 PNG при старте приложения и не декодируй весь каталог перед показом Home. Используй WebP по мере надобности.
- Не добавляй CDN, внешние шрифты, сервисы картинок или запросы к API для статических обложек.

## Проверка и результат
Проверь один раз desktop и mobile: корректная игра/обложка, пропорции, лица и ключевые предметы не обрезаны, названия читаются, нет горизонтальной прокрутки, прямое открытие без заставки. Выполни существующую сборку/typecheck, если применимо; не создавай избыточные тесты на замену картинок.
В конце перечисли изменённые файлы и соответствия 15 обложек. Укажи пропущенные/неоднозначные игры, если есть.
Не делай merge, production-деплой, платежи, миграции БД и массовое переименование файлов вне задачи.
