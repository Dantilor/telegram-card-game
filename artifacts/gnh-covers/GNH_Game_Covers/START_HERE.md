# Новые обложки GameNight Host

15 самостоятельных изображений в общей фиолетовой, розовой и бирюзовой гамме. Названия не встроены в картинки: они остаются чётким текстом в приложении.

1. Распакуй папку GNH_Game_Covers в проект, открытый в Cursor.
2. Отправь Cursor: «Прочитай GNH_Game_Covers/CURSOR_TASK.md и выполни задание. Подключи новые обложки к существующим играм по ASSET_MAP.json. Сохрани реальные данные и всю логику приложения. Без приближения картинок и без заставки при входе в игру».
3. Для просмотра всех обложек открой PREVIEW.html после распаковки.

- assets/ — готовые для сайта WebP в полном разрешении.
- originals/ — оригинальные PNG.
- ASSET_MAP.md и ASSET_MAP.json — соответствие игре и файлу.
- build-prompts.json — точные описания, использованные для создания иллюстраций встроенной генерацией изображений.

Иллюстрации передают атмосферу игр; их реквизит не добавляет новые правила, роли или механики в приложение.
