# Портал и новые широкие обложки

Это дополнение к предыдущему набору из 15 новых обложек. Здесь — широкие варианты именно НОВЫХ изображений Cards, «Кто тут кто?» и «Где мы?», а также новый портал целиком.

1. Распакуй GNH_Responsive_Images в проект Cursor.
2. Отправь: «Прочитай GNH_Responsive_Images/CURSOR_TASK.md и выполни задание. Подключи новый портал и расширенные НОВЫЕ обложки из assets, с desktop/mobile переключением. Исправь пропорции контейнеров, сохрани всю информацию и логику приложения».
3. Открой PREVIEW.html после распаковки, чтобы увидеть все изображения в правильных пропорциях. Ширину предпросмотра можно переключать без установки зависимостей.

assets — WebP для сайта; originals — PNG в исходном разрешении; styles и components — пример геометрии для адаптации, не готовая замена всей главной.

Формат файла сам по себе не исправляет CSS-растяжение. Нужно подключить правильную версию и соответствующие ей пропорции контейнера. Точные размеры находятся в ASSET_MAP.json.
