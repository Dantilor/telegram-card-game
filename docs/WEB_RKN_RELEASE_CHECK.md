## 1. Смысл отметки «криптографические средства: не используются»

В форме уведомления РКН поле про СКЗИ обычно относится к **специальным криптографическим средствам защиты информации** (сертифицированные СКЗИ, шифрование баз «на диске» как отдельная мера), а не к обычному HTTPS/TLS транспорта.

Наличие TLS у Timeweb / браузера **само по себе не делает отметку «не используются» автоматически ложной**.  
Рекомендация: при актуализации формы отдельно подтвердить у оператора, что имелись в виду именно СКЗИ, а не TLS.

Отметка «трансграничная передача: осуществляется» в **основном** уведомлении ≠ отдельное уведомление о трансграничной передаче по ст. 12 152-ФЗ. Это разные процедуры.

## 3. Вывод

1. **Отдельное срочное «новое» уведомление о трансграничной передаче по ст. 12** только из-за WEB-релиза **не следует автоматически** из факта отметки «осуществляется» в основном уведомлении. Нужна юридическая проверка: достаточно ли текущей отметки + описания поручений (Timeweb, ЮKassa, Telegram/Google в политике).
2. **Актуализация основного уведомления желательна** (не блокер кода):  
   - анонимные WEB-аккаунты и session/cookie id;  
   - email не только для чека, но и для восстановления доступа / magic link;  
   - технические идентификаторы (lease, otp hash);  
   - домен WEB.
3. Поле **СКЗИ «не используются»** не трактовать как запрет TLS; при актуализации подтвердить смысл поля.
4. **Проект изменений для согласования с владельцем (черновик):**  
   - дополнить цель №1 категориями сведений WEB;  
   - явно связать email recover с исполнением договора;  
   - обновить перечень ИС/доменов (`play.gamenighthost.ru`);  
   - пересмотреть перечень трансграничных получателей (Google Fonts / Telegram) в политике и, при необходимости, в сведениях РКН.
5. В код и утверждённые legal texts **изменения не вносились** этим отчётом. В РКН **ничего не отправлялось**.

## 4. Практические меры до production (не РКН-отправка)

- Self-host / уже локальные шрифты там, где возможно, чтобы уменьшить зависимость от Google Fonts.  
- Не логировать magic-link токены и email в открытом виде.  
- Держать WEB cookie Secure + SameSite в production.  
- Backup `gnh_supabase` перед миграциями WEB.
