## Поведение интерфейса (соответствует реализации)

| Действие | Результат |
|---|---|
| Баннер появляется | После закрытия первого окна с соглашением («Принимаю» / «Позже»); не блокирует игры |
| «Разрешить Метрику» | Ключ `gnh_metrika_consent_v2 = granted`; загружается `tag.js`, начинаются хиты и цели |
| «Отказаться» | `denied`; запросов к Яндексу и cookie Метрики нет |
| Профиль → «Отключить Метрику» | Остановка, удаление `_ym*`, перезагрузка |
| Профиль → «Включить снова» | Повторное согласие |
| Старые согласия (`v1`, первичное соглашение, cookie-аналитика) | Метрику не включают |
| Адрес с `?`/`#` (код комнаты, токен, возврат оплаты) | Счётчик не запускается до перехода на чистый адрес |
