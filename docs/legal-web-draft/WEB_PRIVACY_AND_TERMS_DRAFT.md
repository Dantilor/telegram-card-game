# GameNight Host WEB — черновик юридических изменений (не публиковать)

**Статус:** draft for legal review. Не активировать в UI и не считать действующим согласием.

## Что меняется относительно Telegram Mini App

1. **Анонимные WEB-идентификаторы** (`web_accounts`) создаются автоматически при первом визите. Это не учётная запись с паролем и не Telegram ID.
2. **Cookie-сессии** (`gnh_sid` HttpOnly + `gnh_csrf`) хранят серверную сессию. localStorage не является источником доверенной идентичности.
3. **Покупка Premium на WEB** оформляется на текущий `web_account_id`, отдельно от Telegram `subscriptions` / Stars.
4. **Необязательный email** — только для восстановления покупок и транзакционных сообщений (OTP, чек). Маркетинг по умолчанию выключен.
5. **Привязка Telegram** — только как подтверждение владения уже оплаченной Telegram-подпиской, не как обычный вход на сайт.
6. Согласия Telegram Mini App **не переносятся** автоматически на анонимного WEB-пользователя.

## Cookie и срок хранения (черновик)

| Данные | Назначение | Срок (предложение) |
| --- | --- | --- |
| `web_sessions` (hash) | аутентификация браузера | TTL сессии + отзыв |
| `web_accounts` | анонимная идентичность | до отзыва / политики хранения |
| `web_entitlements` | право Premium WEB | срок тарифа + архив аудита |
| `web_payments` | платёжный журнал WEB | по требованиям фискального учёта |
| `web_email_otps` | одноразовые коды | минуты + короткая ротация |
| `web_telegram_links` | связь WEB↔Telegram | до отзыва пользователем |

Удаление cookies/данных браузера **может привести к утрате** анонимного Premium без подтверждённого email или Telegram-привязки. Это нужно явно сообщать в UI.

## Платежи и возвраты

- Цены и сроки берутся только с сервера (`plans`).
- Premium выдаётся после проверки платежа у ЮKassa (не по одному return_url).
- WEB-платежи не смешиваются с Telegram Stars / существующими `payments.telegram_id` строками без отдельного решения.

## РКН / обработка ПДн

Перед публичным запуском проверить, покрывает ли уже поданное уведомление: cookie-идентификаторы, email OTP, платёжные метаданные WEB, привязку Telegram ID к WEB-аккаунту. Не считать покрытие автоматическим.
